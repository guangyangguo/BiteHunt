## 探店地图项目 - 初始搭建

### 完成内容
- 创建了探店搜集项目的基础架构（纯前端 HTML/CSS/JS 单页应用）
- 技术栈：Leaflet.js 地图 + 高德地图瓦片 + 自定义标记系统
- 设计风格：现代暗色主题 + 玻璃态面板 + 流动动画

### 文件结构
```
F:/tandian/
  index.html      - 主页面（全屏地图 + 导航栏 + 侧边栏 + 筛选栏）
  css/style.css   - 完整样式系统（暗色主题、响应式、动画）
  js/data.js      - 数据层（6位知名美食博主 + 20家成都店铺数据）
  js/app.js       - 核心逻辑（地图、标记、筛选、搜索、详情面板）
```

### 核心功能
1. 全屏 Leaflet 地图（高德瓦片，国内访问友好）
2. 20个自定义脉冲动画标记（按品类配色）
3. 品类筛选（火锅/川菜/小吃/面馆/烧烤/甜品饮品/创意料理/轻食简餐）
4. 搜索功能（支持店名/菜品/博主名/地址模糊搜索）
5. 侧边栏店铺列表 + 卡片高亮联动
6. 店铺详情面板（评分/人均/地址/推荐菜/博主点评/博主信息）
7. 统计信息展示（店铺总数/博主数/品类数）
8. 响应式布局（桌面端 + 移动端适配）
9. 地图点击标记 → 飞行定位 + 弹出详情

### 数据概况
- 模拟了6位知名美食博主：密子君、盗月社食遇记、唐仁杰、肉肉大搜索、日食记、吃货请闭眼
- 覆盖20家成都美食店铺，品类包含火锅、川菜、小吃、面馆、烧烤、甜品饮品、创意料理、轻食简餐
- 每条数据包含：店名、坐标、品类、人均、评分、博主信息、推荐菜、标签、点评语

## 第二阶段：后端 + AI分析管线（22:15-22:40）

### 架构升级
从"纯前端静态数据"升级为"采集→AI分析→展示"完整管线：

```
前端 (frontend/)  ←→  Flask API (backend/)  ←→  SQLite (data/tandian.db)
                           ↓
                    B站API (视频采集，含wbi签名)
                           ↓
                    LLM API (DeepSeek/OpenAI，提取店铺信息)
```

### 新增文件
- `backend/app.py` - Flask 主服务（端口5000），含完整 REST API
- `backend/database.py` - SQLite 数据库层（bloggers/videos/stores/analysis_logs/config 5张表）
- `backend/services/bilibili.py` - B站视频采集（wbi签名、UP主搜索、视频列表获取）
- `backend/services/analyzer.py` - AI分析管道（LLM调用、结构化提取、地理编码）
- `frontend/admin.html` - 管理后台（博主搜索添加、视频列表、AI分析触发、系统配置）
- `frontend/js/api.js` - 前端API通信层

### 改造文件
- `frontend/js/app.js` - 从静态数据改为 API 动态加载，兼容新旧数据格式
- `frontend/index.html` - 增加管理后台入口链接

### 核心功能
1. **博主管理**：搜索B站UP主 → 一键添加 → 自动拉取视频列表
2. **AI视频分析**：将视频标题+描述+标签送入LLM → 提取店铺名/品类/地址/推荐菜/点评
3. **地理编码**：通过Nominatim将地址转为经纬度坐标
4. **数据持久化**：SQLite存储，支持增量更新
5. **管理后台**：视频列表、状态管理、批量分析、API配置
6. **前端动态加载**：地图从API实时获取数据，支持离线回退到静态数据
